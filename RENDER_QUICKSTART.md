# 🚀 Render Quickstart - Deploy in 10 Minutes

## Prerequisites
- [Render account](https://dashboard.render.com) (free tier works)
- GitHub repo pushed with your SafeSpace code
- AWS/S3 account (for evidence storage) or MinIO server

---

## Step 1: One-Click Deploy (Easiest)

1. Push your code to GitHub
2. Go to [Render Blueprints](https://dashboard.render.com/blueprints)
3. Click **"New Blueprint Instance"**
4. Connect your GitHub repo
5. Render will automatically:
   - Create PostgreSQL database
   - Create Redis instance
   - Deploy backend service
   - Run migrations

---

## Step 2: Manual Setup (More Control)

### Create Services
```bash
# Order matters!
1. Dashboard → New + → PostgreSQL → Name: safespace-ug-db
2. Dashboard → New + → Redis → Name: safespace-ug-redis
3. Dashboard → New + → Web Service → Connect your repo
```

### Configure Backend Service
| Field | Value |
|-------|-------|
| Name | `safespace-ug-backend` |
| Root Directory | (leave empty) |
| Build Command | `cd backend && npm install && npx prisma generate && npm run build && chmod +x render-entrypoint.sh` |
| Start Command | `cd backend && npm run start:render` |
| Plan | Standard ($7/month) |

### Environment Variables

**Auto-generated by Render (don't set manually):**
- `DATABASE_URL` - From your PostgreSQL service
- `REDIS_URL` - From your Redis service

**Required (set manually in Dashboard):**

```bash
# Run these locally to generate secrets
openssl rand -base64 32  # JWT_ACCESS_SECRET
openssl rand -base64 32  # JWT_REFRESH_SECRET
openssl rand -base64 32  # SESSION_SECRET
```

**Add to Render Dashboard → Environment:**
```
NODE_ENV=production
PORT=10000
JWT_ACCESS_SECRET=<paste-generated-secret>
JWT_REFRESH_SECRET=<paste-generated-secret>
SESSION_SECRET=<paste-generated-secret>

# S3/Storage
STORAGE_ENDPOINT=https://s3.amazonaws.com
STORAGE_BUCKET=safespace-ug-evidence
STORAGE_ACCESS_KEY=<your-s3-key>
STORAGE_SECRET_KEY=<your-s3-secret>
STORAGE_REGION=us-east-1

# Email (Gmail example)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=<your-app-password>
SMTP_FROM=your-email@gmail.com

# CORS (update with your actual URLs)
CORS_ORIGINS=https://safespace-ug.onrender.com
AUTH_APP_URL=https://safespace-ug-auth.onrender.com
COMMITTEE_DASHBOARD_URL=https://safespace-ug-dashboard.onrender.com
PARTICIPATION_PORTAL_URL=https://safespace-ug-portal.onrender.com
```

## Step 3: Verify Deployment

### Test Health Endpoint
```bash
curl https://safespace-ug-backend.onrender.com/health
```
Should return: `{"status":"ok","env":"production",...}`

### Check Database
```bash
render psql --database safespace-ug-db -c "\dt"
```
Should show tables: `Case`, `Complaint`, `User`, etc.

### Test Registration
```bash
curl -X POST https://safespace-ug-backend.onrender.com/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "password": "TestPassword123!",
    "firstName": "Test",
    "lastName": "User",
    "systemRole": "COMPLAINANT"
  }'
```

## Common Issues

### "Cannot find module"
→ Build command issue. Use full path:
```bash
cd backend && npm install && npx prisma generate && npm run build
```

### "Database connection failed"
→ Check:
1. PostgreSQL service is running
2. Same region as web service
3. DATABASE_URL auto-populated

### "Redis connection failed"
→ Check:
1. Redis service is running
2. Same region as web service
3. REDIS_URL auto-populated

### "CORS error"
→ Your frontend URL not in CORS_ORIGINS. Add it:
```
CORS_ORIGINS=https://your-frontend.onrender.com,https://safespace-ug-backend.onrender.com
```
