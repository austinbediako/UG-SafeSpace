## Manual Deployment Steps

### 1. Prerequisites

- [Render](https://render.com) account (free tier available)
- [GitHub](https://github.com) account with your SafeSpace repo pushed
- Your frontend apps ready (optional - can host separately)

### 2. Deploy Backend Service

#### Step 2.1: Create New Web Service

1. Log into [Render Dashboard](https://dashboard.render.com)
2. Click **"New +"** → **"Web Service"**
3. Connect your GitHub repository
4. Configure the service:

| Setting | Value |
|---------|-------|
| **Name** | `safespace-ug-backend` |
| **Runtime** | `Node` |
| **Build Command** | `cd backend && npm install && npx prisma generate && npm run build && chmod +x render-entrypoint.sh` |
| **Start Command** | `cd backend && npm run start:render` |
| **Plan** | Standard ($7/month minimum for always-on) |

#### Step 2.2: Create PostgreSQL Database

1. Dashboard → **"New +"** → **"PostgreSQL"**
2. Name: `safespace-ug-db`
3. Plan: Standard (or Starter for testing)
4. Region: Same as your web service (e.g., Oregon)
5. Copy the **Internal Database URL** for env vars

#### Step 2.3: Create Redis Instance

1. Dashboard → **"New +"** → **"Redis"**
2. Name: `safespace-ug-redis`
3. Plan: Standard (or Starter for testing)
4. Region: Same as your web service
5. Copy the **Internal Redis URL** for env vars

#### Step 2.4: Configure Environment Variables

In your Web Service dashboard → **Environment** tab:

**Auto-generated by Render:**
- `DATABASE_URL` - From PostgreSQL service
- `REDIS_URL` - From Redis service

**Required - Set Manually:**

| Variable | Value | Notes |
|----------|-------|-------|
| `NODE_ENV` | `production` | |
| `JWT_ACCESS_SECRET` | Generate random 32+ char string | `openssl rand -base64 32` |
| `JWT_REFRESH_SECRET` | Generate random 32+ char string | Different from access secret |
| `SESSION_SECRET` | Generate random 32+ char string | Iron-session encryption |
| `STORAGE_ENDPOINT` | Your S3/MinIO endpoint | e.g., `https://s3.amazonaws.com` |
| `STORAGE_BUCKET` | `safespace-ug-evidence` | Create bucket first |
| `STORAGE_ACCESS_KEY` | Your S3 access key | |
| `STORAGE_SECRET_KEY` | Your S3 secret key | |
| `STORAGE_REGION` | `us-east-1` | Or your region |
| `SMTP_HOST` | Your SMTP host | e.g., `smtp.gmail.com` |
| `SMTP_PORT` | `587` | Or 465 for SSL |
| `SMTP_USER` | Your email username | |
| `SMTP_PASS` | Your email password/app password | |
| `SMTP_FROM` | `noreply@safespace-ug.com` | Sender address |
| `CORS_ORIGINS` | Your frontend URLs | Comma-separated, no spaces |

**Example CORS_ORIGINS:**
```
https://safespace-ug-auth.onrender.com,https://safespace-ug-dashboard.onrender.com,https://safespace-ug-portal.onrender.com,https://safespace-ug-reporting.onrender.com
```

#### Step 2.5: Deploy!

1. Click **"Create Web Service"**
2. Render will automatically:
   - Build your application
   - Run database migrations
   - Start the server
   - Perform health checks

## Storage Configuration (S3 or MinIO)

### Option A: AWS S3 (Recommended for Production)

1. Create S3 bucket: `safespace-ug-evidence`
2. Enable CORS for your Render domain:
```xml
<CORSConfiguration>
  <CORSRule>
    <AllowedOrigin>https://safespace-ug-backend.onrender.com</AllowedOrigin>
    <AllowedMethod>GET</AllowedMethod>
    <AllowedMethod>PUT</AllowedMethod>
    <AllowedHeader>*</AllowedHeader>
  </CORSRule>
</CORSConfiguration>
```
3. Create IAM user with S3 access
4. Copy credentials to environment variables

### Option B: MinIO (Self-hosted or Managed)

1. Deploy MinIO instance (or use managed service)
2. Create bucket and access keys
3. Set `STORAGE_ENDPOINT` to your MinIO URL

2. Generate [App Password](https://myaccount.google.com/apppasswords)
3. Use app password (not your regular password)

**Env vars:**
```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your.email@gmail.com
SMTP_PASS=xxxx-xxxx-xxxx-xxxx  # App password
SMTP_FROM=your.email@gmail.com
```

- **SendGrid**: `SMTP_HOST=smtp.sendgrid.net`
- **Mailgun**: `SMTP_HOST=smtp.mailgun.org`

## Database Management

### Running Migrations Manually

If you need to run migrations manually:

```bash
# Using Render Shell
1. Dashboard → Service → Shell
2. cd backend
3. npx prisma migrate deploy
```

Or via CLI:
```bash
render shell --service safespace-ug-backend
# Then run migrations inside
```

### Database Backup

Render automatically backs up PostgreSQL:
- Daily backups
- 7-day retention on Standard plan
- Download from Dashboard → Database → Backups

### Accessing Database

```bash
# Connect via Render CLI
render psql --database safespace-ug-db

# Or use connection string with pgAdmin/DBeaver
# Get connection string from Dashboard → Database
```

## Troubleshooting

### Build Failures

**Issue:** "Cannot find module '@safespace/types'"

**Solution:** Ensure you're building from the root (monorepo) or install dependencies in correct order:
```bash
# In build command
cd ../.. && npm install  # Install root deps first
cd backend && npm install && npx prisma generate && npm run build
```

**Issue:** "Prisma schema not found"

**Solution:** Check build script copies prisma folder:
```json
"build": "tsc && cp -r prisma dist/"
```

### Runtime Errors

**Issue:** "Cannot connect to database"

**Check:**
1. DATABASE_URL is set correctly
2. Database service is running (same region)
3. Database allows connections from web service

**Issue:** "Redis connection failed"

**Check:**
1. REDIS_URL is set correctly
2. Redis service is running
3. Redis service in same region as web service

**Issue:** "CORS errors in frontend"

**Check:**
1. CORS_ORIGINS includes your frontend URLs
2. No trailing slashes in URLs
3. Protocol matches (https://)

### Deployment Logs

View real-time logs:
```bash
render logs --service safespace-ug-backend --tail
```

## Cost Optimization

### Free Tier Limits

| Service | Free Tier |
|---------|-----------|
| Web Service | 512 MB RAM, sleeps after 15 min idle |
| PostgreSQL | 90-day expiration |
| Redis | 90-day expiration |

### Recommended Production Setup

| Service | Plan | Monthly Cost |
|---------|------|--------------|
| Web Service | Standard | $7 |
| PostgreSQL | Standard | $15 |
| Redis | Standard | $10 |
| **Total** | | **$32/month** |

### Cost-Saving Tips

1. **Use Starter plans** for testing (~$7/month total)
2. **Scale down when not in use** (manual suspend)
3. **Use external database** (if you have existing PostgreSQL)
4. **Use Render's free Redis** for development only

## Updates & Redeploys

### Automatic Deploys

Render automatically redeploys when you push to GitHub:
1. Push to `main` branch
2. Render detects change
3. Builds and deploys new version
4. Zero-downtime deployment

### Manual Deploy

Dashboard → Service → Manual Deploy → Deploy Latest Commit

### Database Migrations on Deploy

The `render-entrypoint.sh` automatically runs migrations on each deploy:
```bash
npx prisma migrate deploy
```

**Note:** For zero-downtime, ensure migrations are backward-compatible.
